For short clips you've already pulled out of a podcast. Each clip on the sequence is transcribed to the word, then the AI picks the juiciest, scroll-stopping line inside it. Tick the ones you like and Mark — you get a coloured marker spanning each hook (name, quote and strength in the comment) so you can jump to it and make the cut yourself. Nothing is cut automatically.
Naifu needs a few engines to do its work. They're downloaded once and kept outside the extension folder, so updating Naifu never re-downloads them — and normal use never touches the network for them again.

Budget ~13 GB of disk if you use everything: ~2.8 GB downloads here, and the rest arrives the first time you actually transcribe (Whisper's speech models) or run the local brain (the qwen model). Both land in the same folder below, so they're one-time too. Using Claude (manual) instead of the local brain saves ~6 GB — skip Ollama entirely.
